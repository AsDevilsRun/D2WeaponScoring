D2 Vault Cleaner dev

Checks your legendary weapons and armor against your lists and finds the junk. Weapons: a copy is junk if a better copy exists or the weapon isn't on your list. Armor: for each set on your list, the best 5 pieces are kept; everything else is junk.

Setup

Dev copy: put your Bungie API key in CONFIG at the top of the script and open this page on the site (asdevilsrun.github.io), where the key's origin matches.

This page needs its own Bungie app. At bungie.net/en/Application, create one with OAuth client type Public, the redirect URL set to this page's address, the origin header set to this site's origin, and the scope Read your Destiny 2 information. Then put its API key and OAuth client ID in CONFIG at the top of the script.
